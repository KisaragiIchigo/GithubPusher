# GithubPusher (CYBER-01)

フォルダをドラッグ＆ドロップするだけで、指定したGitHubアカウントとリポジトリへ、不要なファイルを除外した上でワンクリックコミット＆プッシュできるサイバーネオン調デスクトップアプリケーション。

UIは深遠なミッドナイトブラック（`#030712`）を背景に、鮮烈な**レーザーシアン（`#00f0ff`）**と**ホットマゼンタ（`#ec4899`）**が交錯する**「Cyber Arcade Neon Corridor」**を基調とした、立体的でエッジの効いたサイバーアクリルデザインを採用しています。

---

## 主な特徴

- **フォルダ D&D で即座にGit解析 ＆ 常時どこからでも切り替え可能**  
  プロジェクトフォルダやリポジトリをドロップするだけで、Git状態・ブランチ・リモートURL・変更ファイルを瞬時に自動解析。どの作業画面からでも新しいフォルダを放り込むだけでシームレスに切り替わります（最近使用したリポジトリ履歴やヘッダーナビゲーション完備）。
- **複数アカウントの完全分離・即時切替**  
  GitHub公式の「Select an account」デザインを踏襲した直感的なアカウント選択パネル。個人用・仕事用・サブ用など複数のGitHubアカウント（PAT: Personal Access Token）をローカルで安全に管理し、ワンクリックで切り替え。
- **インテリジェントな自動除外 ＆ プッシュ除外フィルター機能**  
  - **AI作業管理ファイルの恒久自動除外**: `changelogs.json`, `project_style.json`, `.gemini/`, `walkthrough.md` などのAI管理ファイルを自動検知・除外してGitHubをクリーンに保ちます。
  - **OS生成ゴミファイルの自動除外**: Windowsが自動作成する `desktop.ini`, `Thumbs.db` などをスキャン時に即時除外＆プッシュ時のアンステージを徹底。
  - **プリセット除外**: Node.js (`node_modules`, `dist`, `.env`), Python (`__pycache__`, `.venv`), OS/一時ファイルなどをワンクリック一括除外。
  - **機密ファイル自動検知バナー**: `.env` や秘密鍵ファイルが含まれている場合はネオンアンバーで警告を表示し、誤プッシュを未然に防止。
  - **.gitignore 自動更新**: アプリ上で設定した除外ルールをプロジェクトの `.gitignore` へワンクリックで同期保存。
- **リモート既存ファイル（LICENSE/README）の自動統合 ＆ 強制プッシュ対応**  
  GitHubリポジトリ作成時にLICENSE等が含まれていて初回pushが弾かれる問題を、`--allow-unrelated-histories` 自動統合リカバリーまたは `--force` 強制プッシュでスマートに解消。
- **Releaseフォルダ内の .exe 自動検知 ＆ GitHub Releases バイナリアセット自動配信**  
  プロジェクト内の `Release/`, `release/`, `bin/*/Release/`, `dist/` などにビルド済み `.exe` が存在する場合、自動検知して専用パネルがスマートに展開。Gitプッシュと同時にGitHub公式Releasesを作成し、実行ファイルをバイナリアセットとしてワンクリック自動配信（Gitコード履歴への誤混入は自動防止）。
- **コミットメッセージ・クイックプレフィックス**  
  `+feat:`, `+fix:`, `+update:`, `+release:` ボタンをワンクリックするだけで、入力欄の先頭にプレフィックスをスマート挿入/置換。
- **直近Gitコミット履歴のアコーディオン表示**  
  リポジトリの直近コミット（コミットハッシュ・メッセージ・日時・作者）をいつでもワンクリックで展開・確認可能。
- **プッシュ＆Release完了時のクイックリンクボタン**  
  プッシュ成功時に「GitHubで開く」「Releasesで開く」ボタンがネオン表示され、ブラウザから対象リポジトリやリリース詳細へ1秒でアクセス可能。
- **Windowsネイティブ・トースト通知**  
  プッシュやRelease配信の完了時にWindowsのOS標準通知（トースト）を送信。バックグラウンド作業中でも処理終了を手元ですぐに把握できます。
- **リアルタイム計器風ターミナル**  
  Gitの各ステップおよびGitHub Releases作成・exeアップロード進捗の進行ログをリアルタイムにストリーミング表示。

## 使い方

1. **アプリ起動**:
   ```bash
   npm run app
   # または開発サーバー
   npm run dev
   ```
2. **ワンクリックEXEコンパイル（配布用バイナリ作成）**:
   プロジェクトルートの **`コンパイル.bat`** をダブルクリックするだけで、自動でビルド＆ポータブルEXEパッケージングが実行され、`release-build/GithubPusher.exe` が生成されます。
3. **アカウントの登録**:
   右上の設定アイコンまたはアカウント選択モーダル内の「Add a new account」から、GitHubのユーザー名とPersonal Access Token (PAT: `repo` 権限) を登録します。
4. **フォルダをドロップ**:
   プッシュしたいフォルダをアプリの中央にドラッグ＆ドロップします。
5. **アカウントとリポジトリの確認**:
   アカウント選択画面でプッシュ元アカウントを選択し、プッシュ先のリポジトリURLを入力・確認します（直近コミット履歴も確認可能）。
6. **除外設定の調整**:
   プリセットボタンやチェックボックスで、コミットに含めたくないファイル（`node_modules` や機密ファイル）を除外します。
7. **コミット＆プッシュ実行**:
   クイックプレフィックス（`+feat:`, `+update:` 等）を活用してメッセージを決め、「プッシュ実行」ボタンをクリック。
8. **クイック確認**:
   完了するとWindowsトースト通知が表示され、「GitHubで開く」または「Releasesで開く」ボタンからブラウザで即座に確認できます。
